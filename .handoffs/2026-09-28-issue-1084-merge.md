## 6. Traps Hit This Session (read before touching test code)

- **Never write a `page.route` glob like `**/api/...` inside a `/** */` block comment** — the `*/` closes the comment and you get baffling `TS1443: Module declaration names may only use quoted strings` parse errors. Cost two lint+typecheck round-trips in `mock-browserless.ts` and `export-pdf.spec.ts`.
- **Two mocking strategies exist and they are not interchangeable** (now documented in AGENTS.md). Browser-layer `page.route` means the real handler never runs. To test a route's *server-side* behavior you need an env-gated endpoint override.
- **A PR can merge with the e2e suite never run** (#1092 shipped with a "cannot run here" caveat and merged anyway). The full suite is not in CI, so nothing catches this for you.
- **Another agent may be working the same queue concurrently** (#1092 landed mid-flight last session). Check `git log HEAD..origin/develop` and `gh pr list` immediately before merging.
- **`kill -9`ing a stuck `next-server` wipes `~/.cache/ms-playwright/`** → ~55 bogus failures. Recover with `npx playwright install chromium`. If the suite suddenly fails everything, check that cache first.
- **Don't run bare `git checkout <branch> -- .`** to "tidy up" — it clobbers the working tree against your current branch's HEAD. I did this, caught it, and restored with `git checkout HEAD -- .`; verify with `git diff --stat HEAD` being empty.
