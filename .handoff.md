## 6. Traps Hit or Confirmed This Session

- **`vercel env pull` writes `.env.local` by default.** In this repo that is the app env file *and* the target of the `.env` symlink, so a routine CLI command destroys both. Always pass an explicit path: `vercel env pull .env.vercel.bak`. Vercel's own CLI output advertises the default, which is how it happened.
- **Vercel stores Secrets unrecoverably.** `vercel env pull` writes `[SENSITIVE]` for them. Only `Config`-type values (the three `NEXT_PUBLIC_*`) come back real. So Vercel is *not* a backup for `OPENAI_API_KEY` / `FAL_KEY` / `BROWSERLESS_API_KEY` / `DATABASE_URL` / `PREVIEW_TOKEN_SECRET`.
- **`vercel env ls` shows a `created` column — use it to verify secret sync without reading any value.** This is the only safe way to confirm the user updated a secret.
- **Two competing Vercel deploy mechanisms were the real bug**, not a missing secret. The Actions workflow was 100% non-functional; the git integration did everything. "Fix the secret" would have caused duplicate deploys.
- **A Vercel *Preview* deployment is not evidence the app works** — all env vars were Production-scoped, so previews built with zero config yet still reported `Ready`.
- **Supabase API keys and the DB password are unrelated credential families.** A `service_role` JWT can never satisfy a `postgresql://` URL: Postgres compares the password literally and never reads JWT claims. Also: pooler username is `postgres.<ref>`, not bare `postgres`; and the pooler (port 5432) is the right choice over transaction mode (6543) for **Prisma 5**, because transaction mode has no prepared-statement support and Prisma uses them by default.
- **In bash, `read` returns non-zero at EOF even when it captured a value** — under `set -e` that aborts the script. Use `IFS= read -rs PW || true`.
- **A dashboard's copy-paste often includes quotes.** `DATABASE_URL="postgresql://..."` fails Prisma's URL validation. Symptom: `the URL must start with the protocol postgresql://`.
- **Don't nest JS in a bash single-quoted `node -e '...'`** — the `'` in regex character classes silently breaks the quoting. Put the JS in its own `.mjs` and pass values via env vars.
- **ESM resolves imports from the script's location, not cwd.** A script in `/tmp` cannot `import "@prisma/client"` from the repo; use `createRequire("<repo path>")`.
- **An `if:` gate that passes on every push to `develop` means a broken deploy workflow taxes every commit**, docs-only included. Check the gate, not just the failure.
- `ls tests/` does not recurse — use `git ls-files 'tests/**'`.
- Don't quote a commit's hash inside the file that commit carries; use `git log -N`.
